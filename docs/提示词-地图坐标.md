# 提示词：让正文附带你在地图上的坐标（v2 · 配合坐标世界书）

> **你只需要做一件事**：把「第二节」的**瘦身版**整段复制，粘到预设里新增的一条提示词中。
> 插件**不会**改你的预设文件，也不会改你的原世界书。
>
> **v2 变化**：预设里那张 ~900 token 的固定锚点表**搬家了**——
> 现在坐标由插件自建的世界书《世界舆图·坐标表》**按需提供**（正文提到某地才注入该地坐标，不提不花 token），
> 每回合还会自动注入一段「[地理态势]」= 当前位置 + 周边地点 + 地界规则。
> 预设只留输出契约，**每轮净省约 400~600 token**，而且坐标不再靠模型现编。

---

## 一、怎么粘（30 秒）

1. 酒馆 → **AI 响应配置（OpenAI）→ 提示词管理器**，当前预设应为 **`夏瑾 天琴座 V2 Beta 1.01`**。
2. 新建一条提示词：
   - 名称：`🗺️地图坐标`
   - 角色（role）：`user`
   - 系统提示词（system_prompt）：**不勾**
3. 把下面第二节代码块里的内容整段粘进「内容」。
4. 启用它，并**拖动排序**到 **「📘格式姬」之后、「📔快速模式（3选1）」之前**。
5. 保存预设。

> 为什么放这儿：这一段的邻居是「格式姬」（定义非文学格式）与「选项」，模型在这附近对"额外输出格式"最敏感。

## 二、提示词正文（瘦身版 · 配合坐标世界书使用）

```
[地图坐标]
Haruki，除既有的非文学格式外，你还必须在本回合的 <UpdateVariable> → <JSONPatch> 里写入地图坐标变量。

[必写变量]（一次 replace 写入整个 /地图 对象，不要拆成多条）
· 坐标：数组 [x, y]，范围 -500~500 的数（正东/正南为正，向西/向北为负）
· 层级：当前地点，必须与「世界.当前地点」的分层地名一致，用「·」连接、不含环境描述
· 时间：与「世界.当前时间」完全相同
· 高度：整数，单位「里」，向上为正，无垂直位移填 0

[坐标系]
· 原点、轴向与换算比例以世界书条目「[舆图]坐标系总纲」为准（1 坐标单位 ≈ 15 亿里）
· 世界书《世界舆图·坐标表》里的「[舆图]地点·X」条目给出该地的精确坐标——提到该地时直接采用，不要自己换算
· 每轮消息里的「[地理态势]」块给出当前位置、所在地界与周边距离——与其保持一致，不得瞬移到别处
· 上述来源都没有的地点，按世界书给出的方位与距离换算；同一父级下的地点要彼此分开
· 「层级」写到有地理意义的那一级为止（…·神都·长乐坊·醉仙楼 即可）；方位词只用来算坐标，不要写进「层级」

[连续性]
· 若与上一回合在同一地点，坐标必须与上一回合完全相同（直接照抄 <status_current_variables> 里 /地图 的旧值）
· 只有明确发生跨州、跨域远行、传送或瞬移时，才允许一次跳变超过 150；此时应在正文交代耗时/乘骑/传送
· 方位必须与世界观一致，严禁把南部势力放到北侧

[格式示例]
{"op":"replace","path":"/地图","value":{"坐标":[0.9,0.5],"层级":"中央神州·大周仙朝·神都·宫城区·慈宁宫","时间":"元会历·3726年·12月24日·戌时末","高度":0}}
```

## 三、配套开关（插件悬浮窗 → 设置 → 坐标世界书与地理态势）

| 操作 | 作用 |
|---|---|
| **生成并挂载坐标世界书** | 把底图同步成《世界舆图·坐标表》并挂为角色卡附加书（原世界书零改动；写完读回校验） |
| 底图变更后自动同步进世界书 | 拖动/生成/导入底图后 2 秒自动重写坐标书（单向：底图 → 世界书） |
| 每回合注入「地理态势」 | 当前位置 + 地界归属 + 周边距离 + 地界规则；关掉则只靠世界书绿灯条目 |

> 没挂载坐标世界书时，第二节照样能用：模型会按世界书方位自己换算坐标（精度下降），
> 也可以改用下面第四节里的完整版（自带锚点表）。

[地图坐标]

· 时间：与「世界.当前时间」完全相同
· 高度：整数，单位「里」，向上为正（如摘星悬岛为 3000000000，北冥黑渊为 -6666667），无垂直位移填 0

[坐标系]（**神都洛阳 = (0,0) 是原点**；正东为 +x，正南为 +y，向西/向北为负，范围 -500~500）

## 五、为什么写进 `<JSONPatch>` 而不是正文新标签

1. 你的卡里已有正则 **`[不发送]去除变量更新`**（仅提示词），它会把整个 `<UpdateVariable>…</UpdateVariable>`
   从**发给模型的历史**里剥掉 —— 所以这份坐标**不占历史 token**，不像在正文里加标签那样每轮都付费。
2. 不用新增正则，不用改动 MVU 的格式块，MVU 会把它当普通变量写进 `stat_data.地图`。
3. 插件监听 `Mvu.events.VARIABLE_UPDATE_ENDED` 就能拿到，且轨迹能**从存档消息全量重建**（编辑/删除/重 roll 自动纠正）。
4. 模型每轮都能在 `<status_current_variables>` 里看到自己上一轮写的 `/地图`，因此同一地点天然不会漂移。

## 六、备选放置位置：世界书（只影响角色卡，不污染其他角色）

如果你不想让这条规则影响其他用同一预设的角色，可以改放进世界书：

1. 打开世界书 **`《道渊》v5.4.2`**，找到条目 **`[mvu_update]变量输出格式`**（uid 229，常驻、深度 0）。
2. 在它的 `rule:` 列表末尾追加一行：
   ```
   - 每回合还必须在 <JSONPatch> 中写入 /地图 对象：{坐标:[x,y], 层级, 时间, 高度}，坐标系与锚点见预设中的「🗺️地图坐标」条目
   ```
3. 如果没有用预设那条，就把第四节的完整规则整段贴进这个条目的 `content` 末尾。

两种方式**选一种即可**。预设方式改动最小；世界书方式作用域最干净。

## 七、不装提示词也能用（降级路径）

插件的轨迹有两条数据通道：

| 通道 | 需要提示词吗 | 精度 |
|---|---|---|
| `/地图/坐标` | 需要 | 精确到世界坐标，可显示城内移动 |
| `世界.当前地点` 地名查表 | **不需要** | 精确到"已知地名对应的点" |

也就是说：**现在就能用**。插件会直接读 `世界.当前地点`（你卡里本来就每回合强制更新），
按 `·` 分层解析出地名，去底图里查坐标，查不到就在父节点附近自动落点并标为「待定位」（虚线圈），
你拖一下确认即可。装了提示词之后，轨迹会从「地名级」升级到「坐标级」，城内移动也能画出来。

## 八、人物移动规则（可选加餐）

> 用了坐标世界书的话：把这段粘到插件「设置 → 坐标世界书与地理态势 → 人物移动规则」文本框即可，
> 它会作为**蓝灯条目 `[舆图]人物移动规则`** 随书常驻注入（推荐——距离换算跟坐标系统同源，随书分发）。
> 不用坐标书的话：整段粘进预设提示词末尾。

```
[人物移动规则]
· 距离口径：世界书与舆图给出的距离自带约 1000 倍夸张倍率，按数字直接换算，不要用现实尺度校正。
· 距离参照：中州/南州/北冥横穿约 2500~3000 亿里（167~200 格）；神都到各大宗门以数百亿里起步。
· 各境界日行速度（1 坐标格 ≈ 15 亿里）：
  凡人 日行数万里，可忽略不计；
  金丹以下 御器/御剑，日行数百万里（不足 0.01 格）——跨域必须依赖传送阵；
  金丹、元婴 飞行，日行数千万里（约 0.01~0.05 格）——跨域基本依赖传送阵或飞舟；
  化神及以上 超高速肉身飞行为主、可短暂瞬移，日行数十亿里（约数格），跨大区以月计；
  合体期和大乘前期 真正能瞬移，瞬移+飞行交替，日行数百亿里（数十格）：跨一个大区约半天到三天；
  大乘后期/渡劫期（最顶级）掌握法则，数秒横跨大陆（2500 亿里 ≈ 170 格）。
· 远距离移动优先传送阵或飞舟；公用传送阵一般只有中型及以上城市才有。
· 硬性约束：赶路方式必须匹配境界，严禁降级移动（如「化神修士走路/骑马从洛阳到合欢宗」）；
  若「[地理态势]」提示位移超限，正文必须补出与境界相符的手段
  （传送阵/飞舟/法宝，大乘后期以上可为法则跨越），否则改写目的地。

```

## 九、叙事地理规则（可选加餐）

> 用了坐标世界书的话：粘到「设置 → 坐标世界书与地理态势 → 叙事地理规则」文本框，随书蓝灯注入（推荐）。
> 不用坐标书的话：整段粘进预设提示词末尾（删掉第一小节——没有坐标书就谈不上坐标权威）。

```
[叙事地理规则]
· 地点权威：已挂载《世界舆图·坐标表》——地点之间的方位、距离与归属，以本书条目与每轮「[地理态势]」
  为最高依据，优先于世界书地点条目原文里的方位/距离描述（那是未校准的粗略记录）。
  两者冲突时按坐标书写，不要在正文里复述或争论差异。
· 事件地理归属：每个事件都发生在具体坐标上。当前场景只能自然出现「[地理态势]」所列地界与周边的
  人、势力与动向；远处正在发生的事（如东境妖族之战）不得在相距遥远的另一处直接上演——
  埋伏、哨卡、逃兵、余波都不会凭空跨域出现。
· 远方信息入场的唯一途径：亲历者转述、传讯玉简/书信、商队与旅人传闻、官府公告等，
  且应带有滞后与失真；传闻不得直接当成眼前事实描写。
· 例外：正在移动的势力（追击、迁徙、远征）可以跨区出现，但必须交代行进路线与耗时，与移动规则一致。
· 「[地理态势]」每回合更新；切换场景（跨格移动、传送）后，遭遇池按新位置重算，
  旧地点的剧情线只能以信息形式延续。
```
